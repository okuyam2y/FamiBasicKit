# 版ごとに何が変わり、何は変わらないか

*版を改造する人、または複数の版で動かすプログラムを書く人のための文書です。
使うだけなら[使い方](../manual/building.ja.md)を読んでください。*

[English](build-differences.md)

ファミリーベーシックはカートリッジとして出荷されたものです。このリポジトリはそれを
書き換えて何種類かの版を作りますが、**版によって振る舞いが違います**。この文書は
その違いの一覧です。ある版で書いたプログラムと、ある版で身についた癖が、別の版で
黙って壊れないようにするためのものです。

## どの版もコマンドを増やしていません

**追加した命令語は1つもありません。** どの版も、元の ROM が答えていた予約語だけに答え、
その番号も昔のままです。

これは意図してそうしています。**予約語の番号はファイル形式そのもの**で、`.sav` にも
カセットにもディスクにも、その1バイトが入ります。何を失うかは正確に書く価値があります。
**既存の語の番号を変える／新しい語に他の語が使っている番号を与える**と、過去に保存した
全プログラムが黙って別のプログラムになります。一方、**どこも使っていない番号に新しい語を
置く分には、過去の保存データは変わりません** — 予約語表は項目ごとにトークンのバイトを
持っているので、後ろの項目の番号はずれないからです（`docs/token-numbering.md`）。位置で
引くのは**分岐表**の方で、その途中に足すと以降の処理が1つずつずれます（レビューで判明）。
これを守るための規則は `docs/token-numbering.md` にあり、追加の登録簿は空のままです。

代わりに変わったのは、**既存の語の意味**です。該当するのは2語だけで、どちらもディスク版の
`SAVE` と `LOAD` です。

## 版の一覧

|---|---|---|---|---|

| プログラム領域 | V3 は `$6000-$7FFF`、V1/V2 は **`$7000-$7FFF`** | `$6000-$9FFF` | `$6000-$7FFF` | 未定 |
| 領域の大きさ | V3 で 8KB、**V1/V2 で 4KB** | 16KB | 8KB | 未定 |

領域の大きさと `BYTES FREE` の表示は**別の数**なので、表でも分けてあります（表示は
BASIC が自分用に取る分を引いた値）。実測値は `README.md` から、ディスク版のものは
`fb-fds.py` が報告する値です。

### ディスク版の「完成」が指す範囲

`SAVE` と `LOAD` は、本物のファミコン（RAM アダプター＋FDSKey）で打鍵して確認しました
（保存 → 一覧を消す → 読み込み → `LIST` でプログラムが戻る）。

**今のイメージは、一連の流れを実機で通してあります**（2026-08-25・MiSTer・人手ゼロ）:
起動してバナーが出る → 打鍵で `SAVE "HWTEST"` → BIOS のエラー番号が 0 → `LOAD` で戻る →
`BG GRAPHIC` → SD カードからディスクを回収してバイトで検める（ファイル数が 3→4、
新しい見出しは `03 03 10 HWTEST`、`$603A` に読み込み、署名と終端ポインタが大きさと合う、
**変化したのは全部で31バイト**）→ 電源を入れ直すとバナーが出て、プログラムは戻っておらず、
`LOAD` と打てば戻る。

**まだ一度もしていないのは、ドライブ本体を使った実ディスクへの書き込み**です。
ここまでの往復はどれもディスクのモーターを回していません。

表が「完成」に見えることより、ここを書いておくことの方が大事です。「エラーが出ていない」
は検証ではなく、「実機確認済み」は**特定のイメージについての主張**です。

PC 側の道具には別の判定があります。**本物のファミコンが書いたディスク**からプログラムを
取り出して入れ直すと、ディスクが**バイト単位で完全一致**します。「それらしいものが表示
された」より強く、**機械と同じバイトを組めている**ということです。

**V1 と V2 は領域が `$7000` から始まる**ので、始点を動かさずに広げると 4KB で頭打ちに
なります。V3 は `$6000` から始まるので 8KB まで届きます。詳細は [ram-expansion.ja.md](ram-expansion.ja.md)。

### その前に、答える語の数が違います

V3 の予約語表は 109 項目、**V2.1A は 88 項目**です（演算子 `XOR`〜`*` の15個を含めた表の
総数。除くと 94 と 73）。どちらの数え方でも差は同じ 21 語で、V3 が足しているのは
`AUTO` `BACKUP` `BGGET` `BGPUT` `BGTOOL` `CAN` `CLICK` `CRASH` `DELETE` `ERL` `ERR`
`ERROR` `FILTER` `FIND` `GAME` `INSTR` `RENUM` `RESUME` `SCREEN` `TR` `VCT` で、
V2.1A にしか無い語はありません。

**ディスク版はどちらの版からも組めます**。∴ この21語が使えるかどうかは、
ディスクかどうかではなく**組んだ元の ROM** で決まります:

- **V2.1A から組んだ場合** — **21語はどれも使えません**（`GAME`・`BGGET`/`BGPUT` を含む）。
  これは**土台の ROM の性質**であって、ディスク版が取り上げたわけではありません
- **V3 から組んだ場合** — `GAME` 以外は使えます。`GAME` はディスク版が潰しています
  （内蔵プログラムは `$E000-$FFFF` にあり、ディスクではそこが BIOS のため）。
  打つと `?SN ERROR` になります。`BGGET`/`BGPUT` は使えて、
  バッファは領域の上端と一緒に `$7C00` へ移ります

グラフィックエディタはどちらにもありますが、入り方が違います。V2.1A 版はタイトルメニューを
残しているので `SYSTEM` → `2` で `BG GRAPHIC` に入り、V3 は `BGTOOL` 命令として持っていて
メニューを必要としません。

### `BGGET`/`BGPUT` のバッファは領域の上端について動きます

V3 のこの2語は 1KB のバッファを共有していて、それが**プログラム領域の上端に貼り付いて
います**。∴ 領域を広げると**バッファも動きます** — 8KB 版で `$7C00-$7FFF`、
16KB 版で `$9C00-$9FFF`。素の V3 は `$6C00` です。

`POKE`/`PEEK` でこの辺を触るなら重要です。**版ごとに番地が違う**ので、素の番地を
広げた版で読むと、**自分のプログラムの途中**を読むことになります。

### 整数リテラルの範囲が版で違います

**V3 の整数リテラルは符号付き16ビット**（`-32768`〜`32767`）で、V2 系は `0`〜`65535` です。
同じ `PEEK(50976)` が V2.1A では通り、V3 では `?OV` になります。∴ これは値ではなく**版**の
話です。`PEEK`/`POKE` が届く番地はどちらも同じで、V3 では負の数か `&H` で書きます。

## Disk BASIC — `SAVE` と `LOAD` が何になったか

**ディスクに入るプログラムは1本です。もう一度保存すると、前のものが置き換わります。**
`LOAD` は名前で選ばず、そこに在るものを読みます。Disk BASIC にはこの2語しかありません
（一覧も削除もありません）。**書式とエラー番号は[使い方](../manual/building.ja.md)**にあります。

**保存ルーチンは容量を食っていません。** 内蔵の会話プログラムの台詞の上に置いてあり、
そこはディスク版では**到達できない**からです。根拠は `tools/fb-reach.py` で、主張ではなく
道具です — 「この番地は走り得るか」に、分岐表を**読む命令が届く所からだけ**辿って答えます。

この2語のほかに、ディスク版が構造として変えているもの:

| | カートリッジ | ディスク |
|---|---|---|
| 文字の絵 | CHR-ROM | CHR-RAM（ディスクから読む） |
| 内蔵プログラム | `$E000` 以上の ROM | **無い** — ディスクではそこが BIOS |
| 電源投入時 | タイトルメニュー | GAME BASIC へ直行（`SYSTEM` でメニューへ戻れる） |

## MMC5 で `POKE` が届くもの

16KB 版は `$6000-$9FFF` を全部 RAM にしますが、MMC5 自身のレジスタは
`$5000-$5FFF` にあるので届きます。どの WRAM バンクがどれかは
`docs/mmc5-wram-banks.ja.md` にあります。

## VRC7 は作っていません

⚠️ **16KB のフリーエリアと VRC7 の FM 音源は両立しません。** FM のレジスタは
`$9010`/`$9030` にあり、そこは 16KB 版が RAM にしている `$8000-$9FFF` の中です。
∴ 16KB 版で `POKE 36880` と書いても、音源ではなく RAM に書きます。
**どちらか一方**で、別々の ROM になります（カートリッジはマッパーを1つしか持てません）。
